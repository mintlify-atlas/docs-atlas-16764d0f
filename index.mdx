## Why Televisión Écija Media Manager?

Managing multimedia content across distributed storage locations can be challenging. Televisión Écija Media Manager provides a centralized platform to organize, search, and manage videos, images, and other media files efficiently.

## Architecture Overview

Televisión Écija Media Manager is built with a modern stack designed for reliability and performance:

- **Frontend**: Angular 21 with TypeScript for a responsive, type-safe user interface
- **Backend**: Express.js (Node.js) REST API with JWT authentication
- **Database**: MySQL with automated backup system
- **Storage**: Distributed file storage with flexible location management
- **Deployment**: Docker Compose for easy container orchestration
