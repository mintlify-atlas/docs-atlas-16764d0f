## Get Statistics

<ParamField path="GET" required>
  /api/stats
</ParamField>

Retrieve comprehensive statistics about the media library, including total items, breakdown by type and year, and storage information.

### Authorization

Requires valid authentication token (any role).

### SQL Queries

**Total media count:**
```sql
SELECT COUNT(*) as total FROM media_items
```

**Breakdown by media type:**
```sql
SELECT ct.name, COUNT(*) as total
FROM media_items m
JOIN media_types ct ON m.media_type_id = ct.id
GROUP BY ct.name
```

**Breakdown by publication year:**
```sql
SELECT publication_year, COUNT(*) as total
FROM media_items
WHERE publication_year IS NOT NULL
GROUP BY publication_year
ORDER BY publication_year DESC
```

**File paths for storage calculation:**
```sql
SELECT media_path FROM media_items
```

## Storage Calculation Details

### Media File Size

The endpoint calculates total media storage by:

1. Querying all `media_path` values from `media_items`
2. Using `fs.statSync()` to get file size for each existing file
3. Summing all file sizes in bytes

```javascript
for (const file of files) {
    if (fs.existsSync(file.media_path)) {
        const stats = fs.statSync(file.media_path);
        totalBytes += stats.size;
    }
}
```

### Disk Space Information (Linux/macOS)

On Linux and macOS systems, the endpoint uses the `df` command to get disk statistics:

```bash
df -k "/path/to/media"
```

This provides:
- **total**: Total disk capacity
- **used**: Used disk space  
- **free**: Available disk space
- **usedPercentage**: Percentage of disk in use

<Note>
Disk space statistics are only available on Linux and macOS platforms. On other platforms, these values will be 0.
</Note>

### Size Formatting

File sizes are formatted using the `formatBytes()` helper function:

```javascript
function formatBytes(bytes, decimals = 2) {
    if (bytes === 0) return '0 Bytes';
    
    const k = 1024;
    const dm = decimals < 0 ? 0 : decimals;
    const sizes = ['Bytes', 'KB', 'MB', 'GB', 'TB'];
    
    const i = Math.floor(Math.log(bytes) / Math.log(k));
    
    return parseFloat((bytes / Math.pow(k, i)).toFixed(dm)) + ' ' + sizes[i];
}
```

## Use Cases

### Dashboard Metrics

Use this endpoint to populate an admin dashboard with:
- Total media count
- Distribution by media type (for charts)
- Historical data by year
- Storage capacity planning

### Monitoring

Monitor system health by tracking:
- Storage growth trends
- Disk space availability  
- Content distribution patterns

### Reporting

Generate reports on:
- Library composition
- Year-over-year growth
- Storage utilization
